# 미검증 출처

확인하지 못한 2건입니다. **인용 전에 직접 열어보세요.** AI가 생성한 인용 목록에서 가장 자주 문제가 생기는 지점입니다.

## 1. 「문화 향유는 사회자본 형성에 어떻게 기여하는가?: 문화 향유의 지역적 맥락을 중심으로」

| 항목 | 내용 |
|---|---|
| 저자 | 이희정 |
| 학술지 | 사회통합연구 7권 2호 |
| 발행 | 2026년 |
| URL | https://www.e-sir.org/archive/view_article?pid=sir-7-2-107 |
| **판정** | **🟡 보류** |

**확인 결과**
- 웹 검색으로 **해당 논문을 찾지 못했습니다.** 저자·학술지·권호 조합이 색인에 걸리지 않음
- 다만 URL의 `pid=sir-7-2-107` 형식은 해당 학술지 규칙(`sir-권-호-시작페이지`)과 **일치**합니다 → URL 자체는 진짜일 가능성 있음
- **2026년 발행 최신호라면 아직 색인되지 않았을 수 있습니다** (가능성 높은 설명)

**할 일**
- [ ] URL 직접 열어 제목·저자·연도 확인
- [ ] 확인되면 PDF를 `_attachments/`에 저장하고 이 노트에 초록 요약 추가
- [ ] 확인 안 되면 대체 문헌으로 교체 (아래 참고)

**검색으로 찾은 대체 가능 문헌 (실존 확인)**
- [문화지수와 사회경제적 변수 간의 상관관계에 대한 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003278600)
- [사회자본 특성이 지역주의에 미치는 영향: 결속형과 교량형을 중심으로](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001570364)
- [문화기반시설의 지역 간 격차와 영향요인 분석](https://kpaj.or.kr/_PR/view/?aidx=36013&bidx=3230)

## 2. 「지방소멸 위기 지역의 청년층 문화 향유 실태와 정책 과제」

| 항목 | 내용 |
|---|---|
| 발행기관 | 한국문화관광연구원 (KCTI) |
| 유형 | 기본연구보고서 |
| URL | https://www.kcti.re.kr/web/board/boardList.do?bbs_id=data01 (목록만) |
| **판정** | **🔴 제목 오류 가능성 높음** |

**확인 결과**
- **이 제목의 보고서를 찾지 못했습니다.**
- 사용자님이 주신 URL도 **개별 보고서가 아니라 발간물 목록 페이지**입니다 → 원래 정확한 링크가 없었다는 신호
- KCTI에 **실제로 존재하는 유사 보고서**: **「인구위기에 따른 지역문화시설 역할 변화예측 및 대응방안 연구」**

**할 일**
- [ ] [KCTI 발간물 포털](https://www.kcti.re.kr/web/board/boardList.do?bbs_id=data01)에서 "인구감소지역", "청년", "문화향유" 검색
- [ ] 실제 제목으로 교체
- [ ] 「인구위기에 따른 지역문화시설 역할 변화예측 및 대응방안 연구」 확보 검토

**검색으로 찾은 대체 가능 문헌 (실존 확인)**
- [인천 청년 문화향유 실태 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002686046) ← **방법론 참고용으로 유용.** 인천 사례를 광주·전남에 그대로 적용 가능
- [지방소멸극복을 위한 지역문화예술산업과 문화유산 활성화 정책 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003235224)
- [지방소멸 대응과 지역경제 활력 해법, 관광에서 찾다 — 2025 지역문화관광포럼](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE12285133)
