# 업체 안내문 모음

업체(발주서를 보내는 거래처)에게 나가는 글 두 가지입니다. 문구는 `order_automation/templates/` 폴더의 txt 파일을 고치면 바로 반영됩니다.
`{my_name}` 처럼 중괄호로 된 부분은 실행 시 자동으로 채워집니다.

| 안내문 | 언제 | 파일 | 보내는 방법 |
|---|---|---|---|
| ① 발주 접수 안내 (최초 공지) | 시스템 시작 전 1회 | `templates/vendor_announcement.txt` | GitHub Actions 에서 `announce` 실행 + 업체 메일 입력, 또는 `python main.py announce --to a@x.com,b@y.com` |
| ② 발주 처리 결과 안내 (매일) | 박경원님 회신 확인 직후 자동 | `templates/vendor_notice.txt` | 자동 (업체별 엑셀 첨부) |

## ① 발주 접수 안내 (최초 1회 공지)

메일 제목: `[영암부부농원 발주 접수 안내] 매일 오전 10시 마감 · 2026년 10월 30일까지`

```
[영암부부농원 발주 접수 안내] 2026년 10월 30일까지 운영

안녕하세요, 한프로듀서입니다.
영암부부농원 발주 접수를 아래와 같이 자동 접수 방식으로 운영합니다.
매일 같은 시간에 한 번에 통합 발주하고, 당일 운송장번호까지 정리해 돌려드리기 위한 것이니 협조 부탁드립니다.

1. 접수 마감 : 매일 오전 10시
   - 오전 10시 이후 도착한 발주서는 다음 날 발주에 반영됩니다.
   - 전날 저녁에 미리 보내주셔도 됩니다. (제목의 날짜 기준으로 모읍니다)

2. 메일 제목 : 반드시 아래 형식 그대로
   - (월)월 (일)일 영암부부농원 발주서
   - 예) 10월 3일 영암부부농원 발주서

3. 첨부 파일 : 엑셀(xlsx) 1개
   - 기존 발주서 양식 그대로 사용 (아래 열이 꼭 있어야 합니다)
     받는분성함 / 받는분주소 / 받는분전화번호 / 박스수량 / 품목명 / 보내는분성명 / 보내는분전화번호
   - 품목명은 "1개 500g 청무화과" 처럼 [개수 중량 상품명] 형식, 박스수량은 숫자만
   - 운송장번호 열은 비워서 보내주세요 (저희가 채워서 돌려드립니다)

4. 처리 흐름
   오전 10시 접수 마감 → 당일 통합 발주 → 영암부부농원 운송장 등록 → 업체별 발주내역 + 운송장번호 엑셀 회신 (당일)

5. 운영 기간 : 2026년 10월 30일까지

문의 : 한프로듀서 010-0000-0000 / k333896@naver.com
감사합니다.
```

## ② 발주 처리 결과 안내 (매일 자동 발송 예시)

메일 제목 예: `[영암부부농원] 10월 5일 발주 처리 결과 안내 - 두리농 (8건 / 운송장 7건)`
첨부: `영암부부농원_1005_발주결과_두리농.xlsx` (발주내역 / 상품별수량 / 운송장조회 3개 시트)

```
두리농 담당자님, 안녕하세요. 한프로듀서입니다.

2026년 10월 5일(월) 영암부부농원 발주 건 처리 결과를 안내드립니다.

■ 발주 요약 : 총 8건 / 8박스
   품목 | 건당 박스 | 건수 | 총 박스 | 운송장 등록
   ------------------------------------------------------------
   청무화과 500g | 1 | 6 | 6 | 6
   청무화과 1kg | 1 | 2 | 2 | 1

■ 운송장 등록 현황 : 7건 / 8건
   미등록 1건은 운송장 등록 후 추가 안내드립니다.

■ 첨부 파일 : 영암부부농원_1005_발주결과_두리농.xlsx
   - [발주내역] 보내주신 발주 건 전체 + 운송장번호 (상품/수량순 정렬)
   - [상품별수량] 상품·수량별 건수 집계
   - [운송장조회] 받는분별 운송장번호 (고객 안내용)

■ 다음 발주 안내
   - 발주서는 매일 오전 10시까지 "(월)월 (일)일 영암부부농원 발주서" 제목으로 보내주세요.
   - 오전 10시 이후 접수분은 다음 날 발주에 반영됩니다.
   - 본 자동 접수는 2026년 10월 30일까지 운영됩니다.

누락이나 오류 건이 있으면 이 메일로 바로 회신해 주세요.
감사합니다.

한프로듀서
010-0000-0000
```

운송장 등록 현황 문구는 상황에 따라 자동으로 바뀝니다.

| 상황 | 문구 |
|---|---|
| 전부 등록 | 전체 운송장번호가 등록되었습니다. 첨부 [운송장조회] 시트를 확인해 주세요. |
| 일부 등록 | 미등록 N건은 운송장 등록 후 추가 안내드립니다. |
| 엑셀 없이 텍스트 회신만 온 경우 | 영암부부농원에서 발주 확인은 되었으나 운송장번호는 아직 등록 전입니다. 등록되는 대로 다시 안내드립니다. |
